# GALA METHOD ENGINE V2

## Іске қосу
1. Node.js орнатылған болсын.
2. Осы ZIP-ті Extract All жаса.
3. Папканың ішінде CMD немесе Terminal аш.
4. `npm.cmd install`
5. `npm.cmd start`
6. Браузерден `http://localhost:3000` аш.

## Бар функциялар
- Видео upload
- MP4 / MOV / WEBM / MKV
- 720p / 1080p / 1440p / 4K
- 24 / 30 / 60 / 120 FPS
- H.264 / H.265
- FFmpeg encoding
- Download
- Job status

Ескерту: TikTok сервері видеоны қайта кодтай алады; бұл сайт оны айналып өтуге кепілдік бермейді.
